Heatmiser V3 Protocol & Library Documentation

A definitive reference and developer guide for communicating with Heatmiser V3 network thermostats over RS485 and UH1 bridges. Replicating the official heatmiser_v3_protocol_3.9.pdf specification with enhanced clarity, exact byte offsets, and interactive tools.

1. Overview & Architecture

The heatmiserv3 Python library provides a robust, low-level and high-level interface for controlling and reading telemetry from Heatmiser thermostats communicating via the Heatmiser Version 3 RS485 protocol.

Hardware Topology

Heatmiser thermostats communicate over a 2-wire, half-duplex RS485 serial bus operating at 4800 baud, 8 data bits, no parity, 1 stop bit. A central master node—typically a Heatmiser UH1 wiring centre or Ethernet/RS485 bridge—originates all bus sessions and forwards commands to individual thermostats (slaves) addressed [1, 32].

In modern home automation setups, the UH1 or RS485 converter connects either via a direct local serial device (e.g. /dev/ttyACM0) or a TCP socket server (e.g. socket://192.168.1.57:102). The heatmiserv3 library establishes a connection to this interface via HeatmiserUH1 and coordinates session arbitration, frame formatting, CRC calculation, and response parsing.

4. How the Library Works

4.1 Master Command Frame Structure

Whenever a command is issued by the library, a 10-byte (read) or (10 + n)-byte (write) bytecode frame is assembled:

Byte # Field Name Value / Expression Description
0 Destination Address 1 – 32 (or 0xFF) Thermostat slave ID. 0xFF (255) is broadcast.
1 Frame Length 10 (Read) or 10 + n (Write) Total length of this frame including the 2-byte CRC.
2 Source Address 0x81 (129) Master controller address (typically 0x81).
3 Function Code 0 = Read, 1 = Write 0x00 to read from DCB, 0x01 to write parameters.
4 – 5 Start DCB Address start & 0xFF, (start >> 8) & 0xFF 16-bit parameter starting address in Little-Endian format.
6 – 7 Read / Write Length len & 0xFF, (len >> 8) & 0xFF Number of bytes. 0xFFFF requests the full DCB for read.
8 .. (n+7) Payload Data n bytes The configuration bytes (omitted on read frames).
n+8 .. n+9 16-bit CRC crc_low, crc_high CCITT-16 checksum computed across bytes 0 to (n+7).

4.2 Slave Response Verification

Upon receiving a command, the thermostat replies with:

  • Write Reply (7 bytes): [0x81, 7, 0, slave_id, 1, crc_low, crc_high]. Verified by _hm_verify_message_crc_uk().
  • Read Reply: 9-byte header + DCB payload + 2-byte CRC. The header contains [0x81, frame_len_l, frame_len_h, slave_id, 0, start_l, start_h, read_len_l, read_len_h].

6. Visual Test Harness: Real-World DCB Dynamics

Writing register values to a Heatmiser thermostat over RS485 does not merely alter memory bytes in the Device Control Block (DCB)—it orchestrates physical relays, drives safety interlocks, updates LCD annunciators, and modulates HVAC heating loops in the real world.

Live Adjacent Digital Twin

In Split View (desktop default), the Virtual Thermostat Digital Twin is rendered adjacent to this guide on the right side of the screen. You can interact with tactile faceplate buttons, adjust physical environment temperatures, observe relay contacts opening and closing, and test safety cutouts in real time.

6.1 Heating Relay Switching & Differential Hysteresis

The central heating relay (connected across Terminals 1 & 2) switches 230V mains or dry-contact signals to central heating motorized zone valves and boiler call-for-heat terminals:

  • Call for Heat: When the ambient temperature drops below Target Setpoint - Switching Differential (DCB Addr 18 and Addr 27), the microcontroller fires Relay 1/2. The physical circuit closes, the boiler fires, and the 🔥 flame icon illuminates.
  • Setpoint Reached: When the ambient temperature reaches or exceeds the target setpoint, Relay 1/2 opens. The boiler shuts down and the flame icon extinguishes.
  • Hysteresis Protection: The 1°C, 2°C, or 3°C differential (DCB Addr 27) prevents rapid boiler short-cycling, extending compressor and burner life.

6.2 Underfloor Heating Overheat Thermal Safety Interlock

When configured for Mode 3 (Built-in Air + Floor Limit Sensor), the thermostat regulates room comfort using air temperature while continuously polling the NTC floor probe embedded in the floor screed:

  • Safety Cutout Threshold: If the floor temperature reaches or exceeds Floor Max Limit (DCB Addr 29, typically 28°C–35°C), the firmware trips an Emergency Thermal Safety Cutout.
  • Forced Relay Disengagement: The heating relay is forcibly opened immediately, even if the room is cold and demanding heat.
  • Real-World Protection: This interlock protects engineered wood flooring from buckling, adhesive breakdown, and cement screed cracking. The LCD flashes FLR HI or a warning badge.

6.3 Domestic Hot Water Dual-Channel Control (PRT-HW)

The PRT-HW model features an independent secondary relay across Terminals 3 & 4 dedicated to domestic hot water (DHW) cylinder valves:

  • Manual Hot Water Boost: Writing 01 to DCB Addr 41 (Unique Address 41) closes Terminals 3 & 4, energizing the cylinder valve and illuminating the 🚿 tap icon.
  • Holiday Suppression: When Holiday Mode is engaged, hot water heating is suppressed for the holiday duration to conserve energy while the property is unoccupied.

6.4 TM1 Time Clock & Countdown Timer Operations

The TM1 operates in three distinct programming modes (DCB Addr 16: 5/2 day, 7 day, or Countdown Timer):

  • Countdown Boost: Setting Countdown Minutes (DCB Addr 26–27, transmitted Little-Endian) energizes the relay and displays the remaining minutes alongside the ⏱️ timer icon. When the counter expires (0 minutes), the relay disengages automatically.
  • Timer Override: DCB Addr 42 allows software overrides (0 = Auto Program, 1 = Constant ON, 2 = Constant OFF).

6.5 Commercial Anti-Tamper Keypad Lockout

In public buildings, rental properties, and commercial installations, keypad locking prevents unauthorized temperature manipulation:

  • Lock Level 1: Full keypad lock (DCB Addr 22 = 1). All tactile front panel buttons are disabled, displaying a padlock 🔒 icon.
  • Tamper Alarm: Attempting to press buttons on the physical faceplate causes the display to flash a red LOC tamper warning and prevents changes.
  • Lock Level 2: Partial lock allowing setpoint adjustment within configured temperature limits.

6.6 Holiday Mode Setback vs. Sub-Zero Frost Protection

Energy conservation and freeze prevention are governed by two safety state machines:

  • Holiday Mode: Setting holiday hours (DCB Addr 24–25) suspends normal scheduled comfort levels and locks the target to the Frost Protect Temperature (DCB Addr 17, default 12°C). The 🧳 suitcase icon is displayed.
  • Standby Freeze Protection: Even when the user turns the thermostat completely OFF / Standby (DCB Addr 21 = 0), an emergency freeze-protection monitor remains active. If the room drops $\le 12^\circ\text{C}$, Relay 1/2 closes and the ❄️ snowflake icon illuminates to prevent burst water pipes.

8. Protocol Gotchas & Clarifications

The official Heatmiser specification contains subtleties that frequently cause integration bugs. Here are critical clarifications:

1. The Endianness Trap: Big-Endian Reads vs. Little-Endian Writes!

Page 4 states: "For those with 2 bytes parameters, when reading, high 8 bits are sent first while for writing the low 8 bit should be sent first".
For Holiday Hours (Address 24) and Countdown Minutes (Address 26):
• When reading from DCB: High byte is at index N, low byte is at index N+1 (Big-Endian).
• When writing command frames: Low byte is sent first, followed by high byte (Little-Endian).

2. Unique Address vs. DCB Index

In the PDF tables, there are two address columns:
• Unique Address: The network address used in write command frames (Bytes 4–5).
• Index in DCB: The zero-indexed byte position in the received read reply payload. These often differ! For instance, on TM1, Program Mode is Unique Address 16, but lives at DCB Index 6.

3. Hour 24 Represents a Cancelled Period

In both heating comfort levels and timer switching periods, an Hour value of 24 (0x18) denotes that this switching interval is cancelled/disabled, not midnight (which is Hour 00).

4. Temperature Sensor Scaling (Divided by 10)

Remote air temperature, floor temperature, and built-in temperature values are returned as 16-bit integers multiplied by 10. A value of 215 represents 21.5°C. If a sensor is disconnected or absent, the value returns 0xFFFF (65535).

9. Python API Specification & Developer Guide

The heatmiserv3 package provides an object-oriented Python interface adhering strictly to the Heatmiser V3 RS485 Protocol 3.9 specification. All convenience methods generate validated CCITT-16 checksummed frames, enforce hardware boundaries, and handle bi-directional telemetry conversion.

class heatmiserv3.connection.HeatmiserUH1(ipaddress=None, port=None, dev=None)

Connection manager and serial transport bridge for Heatmiser UH1 wiring centres and RS485 bus nodes. Supports direct serial ports (e.g. /dev/ttyUSB0, COM3) or TCP-to-serial network bridges (e.g. Moxa, USR-TCP232). Manages connection retry and automatic socket re-opening on bus disruptions.

  • ipaddress (str, optional) – IP address of TCP-to-RS485 bridge.
  • port (str | int, optional) – TCP port number of the bridge (e.g. "102" or 8000).
  • dev (str, optional) – Local POSIX serial device path or Windows COM port name.

class heatmiserv3.heatmiser.TM1Thermostat(address, uh1, model="tm1")
Subclass of HeatmiserThermostat

Model class for the TM1 Time Clock & Countdown Programmer (Model ID 0x05). Provides timer channel overrides, countdown timing (0–1800m), and 5/2 & 7-day multi-period switching schedules.

Timer & Schedule Methods
def set_timer_state(state: int) → list Write Addr 42
Sets manual timer override: 0 = Auto (follows schedule), 1 = Override ON, 2 = Override OFF.
def set_countdown_timer(minutes: int) → list Write Addr 26
Sets countdown timer duration in minutes (0–1800). Automatically converts to 2-byte little-endian format.
def set_weekday_schedule(schedule: list[int]) → list Write Addr 71
Writes 16-byte weekday switching schedule representing 4 periods: [T1_On_H, T1_On_M, T1_Off_H, T1_Off_M, ...]. Cancelled periods are designated by setting Hour to 24.

Python Automation Examples

Example 1: PRT Room & Floor Temperature AutomationPython
from heatmiserv3 import heatmiser, connection

# Connect via serial bridge or direct RS485 adapter
uh1 = connection.HeatmiserUH1(ipaddress="192.168.1.57", port="102")

# Instantiate PRT programmable thermostat at address 1
prt = heatmiser.HeatmiserThermostat(address=1, model="prt", uh1=uh1)

# Configure device operating mode & regulation
prt.set_on_off(1)                       # Turn heating system ON
prt.set_temperature_format("C")         # Use Celsius
prt.set_differential(1)                 # 1°C switching differential
prt.set_target_temp(21)                 # Target comfort: 21°C
prt.set_floormax_temp(28)               # Floor safety cutout: 28°C

# Switch to Remote Air + Floor sensing mode (Mode 4)
prt.set_sensor_selection(4)

# Set 3-hour temporary comfort boost to 23°C
prt.set_temp_hold(minutes=180, temperature=23)
Example 2: PRT-HW Dual Channel Heating & Hot Water BoostPython
from heatmiserv3 import heatmiser, connection

uh1 = connection.HeatmiserUH1(dev="/dev/ttyUSB0")

# Instantiate PRT-HW thermostat at address 2
prt_hw = heatmiser.PRTHWThermostat(address=2, uh1=uh1)

# Read dual channel state
print("Heating Active:", prt_hw.get_heating_state())     # 1 or 0
print("Hot Water Active:", prt_hw.get_hot_water_state()) # 1 or 0

# Engage hot water boost
prt_hw.set_hot_water_boost(1)

# Reset boost back to scheduled auto mode
prt_hw.set_hot_water_boost(0)
Example 3: TM1 Time Clock & Countdown AutomationPython
from heatmiserv3 import heatmiser, connection

uh1 = connection.HeatmiserUH1(ipaddress="192.168.1.57", port="102")
tm1 = heatmiser.TM1Thermostat(address=3, uh1=uh1)

# 2-hour countdown timer
tm1.set_countdown_timer(120)

# Set 7-day vacation setback (168 hours)
tm1.set_holiday_hours(168)

# Configure 5/2 Weekday switching schedule (4 pairs: On H/M, Off H/M)
weekday_schedule = [
    6, 30,  8, 30,   # Time 1: 06:30 On, 08:30 Off
    17, 0, 22, 30,   # Time 2: 17:00 On, 22:30 Off
    24, 0, 24,  0,   # Time 3: Cancelled (Hour 24)
    24, 0, 24,  0,   # Time 4: Cancelled (Hour 24)
]
tm1.set_weekday_schedule(weekday_schedule)
